# متاهة نافس المتكاملة (Nafs Maze Game)

لعبة تعليمية تفاعلية باللغة العربية موجهة لطلبة المرحلة المتوسطة للتدريب والمراجعة على اختبارات **نافس** الوطنية في مجالات **العلوم** و**الرياضيات** و**الفهم القرائي**.

## المميزات والتحسينات الهندسية
- **٣ مراحل متكاملة (٦٧ سؤالاً موثقاً)**:
  - **العلوم**: ٢٥ سؤالاً في الوراثة، الفيزياء، الكيمياء، التصنيف، وعلوم الأرض.
  - **الرياضيات**: ٢٤ سؤالاً تشمل الهندسة، الاحتمالات، المتتابعات، والصيغة العلمية، مع رسوم توضيحية هندسية وخط أعداد تفاعلي.
  - **القراءة**: ١٨ سؤالاً مرتبطة بنصوص القراءة الكاملة (*كتاب السماء*، *رائحة النشارة*، *ساعة بلا شاشات*) مع لوحة نص قابلة للطي.
- **ميكانيكا متاهة متوازنة (12×12)**: تقدم تناسبي يضمن وصول البطل فعلياً إلى باب الخروج عند إتمام المرحلة، مع مطاردة عادلة من الوحش ومؤشر مسافة لحظي.
- **توضيحات تعليمية فورية**: شرح مبسط بعد كل سؤال لترسيخ المفهوم العلمي أو الرياضي.
- **رسوميات متجهة محلية (SVG) ومؤثرات صوتية**: شخصيات مرسومة بدقة دون الاعتماد على روابط صور خارجية، مع مؤثرات صوتية عبر Web Audio API وزر لكتم الصوت.
- **وضعان للعب**: الرحلة المتكاملة (العلوم ← الرياضيات ← القراءة) أو التدريب الحر على أي مادة مباشرة.
- **تصميم متجاوب ودعم لوحة المفاتيح**: يعمل بسلاسة على الحاسوب والتابلت والجوال مع دعم مفاتيح الأرقام `1–4` و `Enter`.

## التشغيل المحلي والنشر على GitHub
```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج:
```bash
npm run build
```
سيتم توليد الملفات الجاهزة للنشر في مجلد `dist/` (مناسبة لـ GitHub Pages أو Vercel أو Netlify).
