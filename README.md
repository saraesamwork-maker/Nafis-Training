# متاهة نافس المتكاملة (Nafs Maze Game)

لعبة تعليمية تفاعلية باللغة العربية موجهة لطلبة المرحلة المتوسطة للتدريب والمراجعة على اختبارات **نافس** الوطنية في مجالات **العلوم** و**الرياضيات** و**الفهم القرائي**.

## خطوات النشر الصحيح على GitHub Pages (لتجنب الصفحة الفارغة)
نظراً لأن المشروع مبني بـ **React + TypeScript + Vite**، فإن المتصفح لا يستطيع تشغيل ملفات `.tsx` مباشرة من الفرع الأساسي دون بناء (`Build`). لكي يعمل رابط GitHub Pages مباشرة:

1. ارفع جميع ملفات المشروع إلى مستودعك على GitHub (بما في ذلك مجلد `.github/workflows/deploy.yml`).
2. من صفحة المستودع على GitHub انتقل إلى:
   **Settings** ← **Pages**
3. تحت قسم **Build and deployment** اختر في **Source**:
   **GitHub Actions** (بدلاً من Deploy from a branch).
4. انتظر دقيقة حتى يكتمل تشغيل الـ Workflow في تبويب **Actions**، ثم افتح الرابط وسيعمل التطبيق مباشرة.

## التشغيل المحلي
```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج يدوياً:
```bash
npm run build
```
سيتم توليد الملفات الجاهزة للنشر في مجلد `dist/`.
